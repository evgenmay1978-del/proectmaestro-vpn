## Что осталось

- Прежний финальный e2e-аккаунт ещё существует. Для его штатного soft-delete
  нужна owner panel session + CSRF (`settings.critical`). Bearer-варианта
  native DeleteCustomer нет; сессию не подделывать, прямым SQL не обходить.
  Штатный DeleteCustomer создаёт события отзыва и сохраняет финансовый журнал;
  выдача подписки прекращается по статусу `deleted`, а не по изменению token.revoked.
- X-ui guard DB/runtime на S1/S3/S4 не установлен. Готового корректного checker нет.
  Простое равенство всех клиентов БД и runtime неверно: учитывать enabled,
  срок, квоту и служебных клиентов. Не внедрять таймер рестартов без этой логики.
- Старые product IDs не мешают подтверждённому пути покупки CDN в боте S1:
  используется `CDNCheckout.dispatch` и актуальный каталог. Новый прогон покупок не нужен.
- STRAVO: финальный APK 1.0.2 (3), исходники `6007623`, Actions `35450556656`,
  PR #4 репозитория `stravo-vpn`. Вход, раздельные подписки и phone/TV-гейты собраны;
  работа финального APK на физических устройствах ещё не подтверждена.

Частные планы ротации и резервные копии остаются вне Git. UUID, ключи, адреса
клиентов и URL подписок в этот документ не переносить. Main/stable OTA не менялись.
