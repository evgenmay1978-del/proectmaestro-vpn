# MaestroVPN mobile 4D component kit — дизайн-спецификация

Дата решения владельца: 01.08.2026.

## Результат

Создать 31 самостоятельный PNG-ассет для чистой мобильной 4D-пересборки MaestroVPN. Каталожный лист используется только как визуальный референс. Вырезать, растягивать или выдавать элементы каталога за готовые ассеты запрещено.

Все новые файлы кладутся только в `design/mobile-asset-redraw/kit/`. Эта работа не меняет Android-код, runtime-атласы, старый интерфейс, backend, TV-компоненты или `tvm_*`.

## Источники истины

1. Выбранный владельцем Home: `design/mobile-4d-references/04-owner-selected-home-2026-07-31.jpg`.
2. Общие требования к арту: `design/mobile-asset-redraw/SPEC.md`.
3. Приложенный владельцем каталог от 01.08.2026 — референс формы, материалов и состава набора, но не источник пикселей.

Визуальный язык сохраняется без импровизации: тёмное ореховое дерево, состаренная бронза и золото, тонкие изумрудные акценты, готическая резьба, дорогой материальный рельеф. Запрещены плоские современные карточки, пластиковые градиенты, неоновые контуры и новые декоративные мотивы.

## Значение суффиксов и геометрия

В новом `kit/` суффиксы `_l`, `_c`, `_r` означают левую, центральную и правую позиционные части элемента, как на каталожном листе. Это не варианты направления света из исходного 15-слойного Home-комплекта.

`home_arc_*` и `home_console_*` создаются на одинаковых внутри своей группы прозрачных холстах шириной 2160 px. Содержимое располагается в своей реальной позиции, поэтому три файла одной группы накладываются без ручной подгонки. Высота холста должна плотно охватывать группу с безопасным прозрачным полем по краям.

Кнопки строятся как совместимый трёхчастный конструктор. Во всех четырёх состояниях контуры, размеры, стыки и альфа-геометрия частей совпадают пиксель-в-пиксель. Меняются только материал, глубина нажатия, свет и цветовой акцент:

- `default` — тёмное дерево и спокойная бронзовая окантовка;
- `pressed` — визуально утопленное состояние, ослабленный верхний блик;
- `selected` — тот же контур с сдержанным изумрудным акцентом;
- `disabled` — тот же контур с пониженной насыщенностью и контрастом.

`button_glow`, `button_highlight` и `button_shadow` содержат только соответствующий эффект, без повторения базовой кнопки.

## Содержание ассетов

- На дуге и консоли нет подписей, названий протоколов, телефонных номеров или иконок действий.
- `separator_gold` и `center_jewel` остаются самостоятельными элементами и не запекаются в соседние слои.
- Статусные панели не содержат текста. Их состояние читается материалом и акцентом: зелёный для `connected`, золотисто-янтарный для `connecting`, красный для `error`.
- `telegram`, `whatsapp` и `max` — самостоятельные узнаваемые глифы без подписей, кнопочной рамки и фона.
- Ни один файл не содержит тень другого компонента.
- Никакой глаз, `MaestroVPN` или иной текст в новый набор не добавляется.

## Формат

- PNG, 8 бит на канал.
- sRGB без встроенного ICC-профиля.
- Альфа-канал у всех 31 файлов.
- `home_arc_*` и `home_console_*`: ширина 2160 px; минимум для принятия — 1620 px.
- Мелкие самостоятельные элементы: достаточная исходная плотность без увеличения каталога; целевой размер 96–192 px для иконок и самоцветов, если больший размер не требуется фактической геометрией.
- У прозрачных краёв нет белой, чёрной или цветной каймы.

## Способ создания

Рекомендуется создать каноническую геометрию каждой группы по визуальным референсам, затем из неё получать состояния и эффекты. Это сохраняет совместимые контуры и не допускает дрейфа между вариантами.

Нельзя независимо импровизировать геометрию каждого состояния. Нельзя создавать один новый спрайт-лист и затем лениво нарезать его: каждый итоговый файл должен пройти самостоятельную проверку границ, альфы и размера.

## Проверка

Набор принимается только при выполнении всех условий:

1. В `kit/` ровно 31 ожидаемый PNG без лишних каталогов и промежуточных листов.
2. Имена совпадают со списком в этой спецификации.
3. Все файлы RGBA, 8-битные, sRGB, без ICC.
4. Ширина всех `home_arc_*` и `home_console_*` равна 2160 px.
5. Части дуги и консоли накладываются в общей системе координат без подгонки.
6. Четыре состояния кнопок имеют одинаковую геометрию и стыки.
7. На прозрачных границах нет каймы или остатков ключевого фона.
8. В PNG нет запечённых подписей.
9. Контактные иконки визуально различимы без текстовых подписей.
10. Git diff не содержит изменений Android-кода, TV-файлов, `tvm_*`, backend, workflow, release или OTA.

## Git-граница

Набор публикуется отдельным asset-only коммитом в ветку `codex/mobile-4d-interface`. Сборка APK для добавления исходников в `design/` не запускается. Перед push выполняются лёгкие проверки PNG, `git diff --check`, проверка точного списка файлов и контроль отсутствия изменений вне `design/mobile-asset-redraw/kit/` и этой спецификации.
