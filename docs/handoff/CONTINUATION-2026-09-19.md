## Остальные пункты

- Прежний финальный e2e-аккаунт оставлен владельцу. Для его штатного soft-delete
  нужна owner panel session + CSRF (`settings.critical`). Bearer-варианта
  native DeleteCustomer нет; сессию не подделывать, прямым SQL не обходить.
  Штатный DeleteCustomer создаёт события отзыва и сохраняет финансовый журнал;
  выдача подписки прекращается по статусу `deleted`, а не по изменению token.revoked.

  используется `CDNCheckout.dispatch` и актуальный каталог. Новый прогон покупок не нужен.
