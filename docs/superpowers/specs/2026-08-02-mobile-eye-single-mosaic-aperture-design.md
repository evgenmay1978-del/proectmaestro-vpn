# Mobile Eye: единая мозаика и динамическая апертура

**Решение владельца:** 02.08.2026
**Ветка:** `codex/mobile-4d-deck`
**База:** `209526e7f217a211e4b2464963870b84762b1933`
**Область:** только мобильный Home; TV, backend, VPN runtime, workflows, Release и OTA вне задачи.

## Подтверждённый дефект

Текущий глаз собирается из трёх разных материалов: открытый глаз, бронзовый squint/closed и
повторно нарисованный поверх них кусок `ring`. Это создаёт чёрные боковые клинья, прямоугольную
заплатку, бронзовое веко и скачок швов мозаики. Сам базовый диск уже имеет подходящий
изумрудный тон; разрушение цвета появляется из-за повторного слоя и чужого века.

## Выбранная архитектура

1. `ring` с мозаикой рисуется ровно один раз базовой 4D-сценой.
2. Живой глаз рисуется только внутри динамической миндалевидной апертуры.
3. При моргании верхняя граница проходит 70% пути, нижняя — 30%.
4. При полном закрытии глаз не рисуется вообще: видна та же зарегистрированная мозаика,
   которая всё время находилась под ним, плюс тонкий тёмно-изумрудный контактный шов.
5. `mobile_eye_squint.webp` и `mobile_eye_closed.webp` не участвуют в runtime-композиции.
   Файлы пока остаются в репозитории для совместимости вспомогательных проверок.
6. Взгляд, радужка, зрачок, catchlight, реакция на касание, blink timing и VPN glow сохраняются.

## Геометрический контракт

- Верхняя и нижняя исходные кривые сначала интерполируются на общем объединённом X-grid.
- Для каждого X итоговый шов:
  `seamY = upperY + (lowerY - upperY) * 0.70`.
- При `closure=0` возвращаются исходные верхняя/нижняя кривые на общем grid.
- При `closure=1` обе кривые совпадают по X и Y с допуском `0.001 px`.
- Высота апертуры убывает монотонно; закрытая апертура имеет нулевую высоту.
- Исходный прямой fit `520 / 822.5` и регистрация радужки не меняются.

## Материал и цвет

- Базовую мозаику не перекрашивать вслепую: измеренный окружающий материал уже лежит в
  целевом диапазоне emerald `H 128–136°, S 78–90%, V 12–18%`.
- Удаляется бронзовый кадр века и коричневая контактная тень.
- Контактный шов: глубокий emerald-black, ширина около `3 px` на канве `520 px`, alpha `0.18`.
- Glow остаётся краевым, но переводится из неонового зелёного в более спокойный изумрудный тон.
- При `closure=1` запрещены пиксели sclera, iris, pupil, catchlight и отдельного века.

## Визуальная приёмка

1. Open: нет чёрной миндалевидной наклейки за пределами апертуры.
2. 25/50/75% blink: нет crossfade, бронзовой плёнки, прямоугольной заплатки и боковых клиньев.
3. Closed: мозаика вне тонкого шва пиксельно совпадает с базовым `ring`.
4. Шов не толще `4 px` на 520-px канве и не выглядит коричневой полосой.
5. Положение, масштаб, взгляд, зрачок, catchlight и touch-gaze не меняются.
6. Диск, логотип, подписи, дуга и прокрутка не меняются этой задачей.
7. Simulator строит три состояния и отдельный лист фаз моргания из одного open asset.
8. Android compile/unit и APK выполняются только GitHub Actions.
