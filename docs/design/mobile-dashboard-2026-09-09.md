# MaestroVPN: одобренный мобильный экран

Владелец одобрил макет 09.09.2026, потребовал оставить «Ввести логин» и Telegram-бот на первом экране, обновить глаз и доставить готовый выпуск через OTA всем клиентам. Контрольный макет: `design/mobile-4d-references/12-approved-mobile-home-2026-09-09.png`. Числа в макете демонстрационные; UI получает срок и CDN-баланс действительного выбранного аккаунта.

- [x] Телефонная ветка использует PhoneDashboard; TV сохраняет TvEskizHome. Кнопка Telegram-бот ведёт в @MaestroSecureVPN_bot, поддержка отдельно в настройках.
- [x] Вход, покупка обычного VPN, серверы, настройки, QR, другое устройство и trial используют существующие callbacks. CDN выбирается явно из доступных маршрутов; обычный Auto не выбирает CDN.
- [x] Деревянные/золотые элементы взяты из исходного artwork. Новый глаз создан ImageGen по исходному изумрудному материалу; веки и глазное яблоко зарегистрированы в одном изображении, закрытие выполняет существующая mesh-анимация. Генератор упаковки: ops/mobile-dashboard-assets.py.
- [ ] Подписанная сборка 1.0.159 / 1015900 на GitHub, повторное использование неизменённых native/libbox артефактов, без тестов и локальных сборок.
- [ ] Публикация APK и метаданных через существующий канал OTA, сохранение старого APK и waypoint 1.0.107. Совпадение подписи со стабильной установленной версией обязательно. Тестовая 1.0.158 с потерянной debug-подписью не подтверждает совместимость обновления.

Новая архитектура, серверные настройки, боты, расчёты и TV-интерфейс не входят в этот выпуск. Android может потребовать системное подтверждение установки. Доступность OTA не означает подтверждённую установку на каждом устройстве.
