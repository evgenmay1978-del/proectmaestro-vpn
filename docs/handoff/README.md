## Что за система (в двух абзацах)
VPN-сервис MaestroVPN: приложение (INCY) + Telegram-боты + панель управления. Четыре сервера:
**S1** 193.17.183.48 (панель, бот, ES-origin), **S2** 85.137.166.237 (rqlite-лидер, второй бот, CZ-origin),
**S3** 46.30.42.151 (NL-origin), **S4** 89.125.19.95 (CDN ingress перед Яндекс-CDN, DE-нода, canary).
Панель = legacy-панель на `127.0.0.1:8910` (рендерит обычную подписку для старых токенов) +
контроллер коммерции на `127.0.0.1:18910` (rqlite; подписки, заказы, баланс ГБ, списание из счётчиков Xray).
Публичный фронт — `https://wapmixx.ru:8911`.

У клиента **две подписки**: обычная `/sub/<token>` = 4 VLESS (🇪🇸🇨🇿🇳🇱🇩🇪) + Naive + AnyTLS,
и CDN `/cdn-sub/<token>` = 4 CDN-ноды (по одной на сервер), которая работает только при активной обычной
подписке и положительном балансе купленных ГБ. Трафик CDN считается на каждом origin’е (`maestro-flat-meter`,
`/usage` на 18085) и списывается джобом `maestro-flat-charge` (timer 2 мин) со **всех четырёх** origin’ов.

## Правила безопасности (нарушение = авария)
- **Российский DPI блокирует `89.125.19.95:443`** — DE-нода живёт на **8443** (UFW открыт, x-ui inbound id=2).
  Не возвращать её на 443.
- **CDN-пути**: Яндекс-эдж пропускает только путь с префиксом `/static/main/video/segment.ts/2c988fd8…`
  (DE-хэш). Страны ходят как `<этот путь>/es|cz|nl|de`, nginx на S4 переписывает путь и проксирует на origin.
  Новые страны добавлять только суффиксом к этому префиксу.
- **Ingress на S4** (`maestro-cdn-ingress.service`, `User=www-data`) — `access_log` можно писать **только** в
  `/run/maestro-cdn-ingress/`; попытка писать в `/var/log` роняет сервис (nginx -t под www-data не может создать файл).
- **rqlite** — 2 voter’а (S2+S3) + клиент S1; потеря лидера = панель не стартует. Если панель в цикле
  `schema unavailable … request transport failed` — `systemctl restart maestro-cdn-rqlite-s3` на S3,
  лидер переизберётся (в панели уже есть ретрай сборки рантайма вместо падения).
- **x-ui на узлах**: клиенты живут в таблице `clients` + `client_inbounds` (не в settings JSON).
  После правок БД — `systemctl restart x-ui` (иначе рабочий конфиг остаётся старым; так сломалась Германия).
- Не перезапускать origin’ы и ingress во время проверок у владельца — это и есть «ноды отвалились по очереди».
