# MaestroVPN mobile asset redraw

Здесь находится готовый исходный комплект для чистой пересборки мобильного
главного экрана. Полные требования и критерии приёмки описаны в
[`SPEC.md`](SPEC.md).

## Содержимое

- [`source/`](source/) — 15 PNG: пять слоёв × свет слева, по центру и справа;
- [`PREVIEW_c.png`](PREVIEW_c.png) — контрольная сборка центрального света без
  текста и глаза.

Каждый файл в `source/` имеет холст 2160×4670, 8 бит на канал и sRGB без
ICC-профиля. `home_wood_*` — RGB; остальные слои — RGBA.

## Порядок сборки

```text
home_wood
home_frame
home_cartouche
home_vines
home_ring
existing mobile_eye_* layers
Playfair title and interactive UI
```

Все слои накладываются в координатах полного холста без ручной подгонки. Варианты
`_l`, `_c`, `_r` внутри каждого слоя имеют одну и ту же альфа-геометрию.

## Жёсткая граница внедрения

- не класть новый комплект поверх `mobile_home_scene.webp`;
- не запекать в арт текст, глаз или тени между слоями;
- после миграции и проверки ссылок удалить заменённый mobile-only плоский
  композит и мёртвые мобильные слои;
- не менять `tvm_*`, TV-компоненты, D-pad/focus/Back и ветки `isTv`;
- не перегенерировать исходники без отдельного решения владельца.
