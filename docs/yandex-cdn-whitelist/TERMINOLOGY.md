# Terminology compatibility note

Status: target-only. Operational documentation uses **olcRTC**. `MASTER_REQUIREMENTS.md` is intentionally byte-for-byte verbatim owner input and contains the historical spelling **OLCTRC**; both names refer to the same excluded transport. Do not normalise or edit the master source. Outside that source, use `olcRTC`; the transport remains out of scope with WDTT, qWDTT, and CSQTT. This note is not evidence that any of those transports was inspected, modified, deployed, or tested.
