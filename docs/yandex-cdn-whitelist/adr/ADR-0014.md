# ADR-0014 — billing suspension

Status: proposed. This is a target decision, not a live change.

## Problem
Choose a safe billing suspension approach without coupling an unproven CDN transport to ordinary VPN.

## Constraints
Ordinary access/identity/subscription/balance stay unchanged; target is independent S1/S2/S3/S4 reconciliation; secrets stay outside docs; WDTT, qWDTT, CSQTT and olcRTC are deferred.

## Alternatives
Use current production path; use an isolated candidate; or apply an unpinned/manual shortcut.

## Trade-offs
Isolation and immutable evidence cost setup work but limit blast radius; shortcut coupling is rejected until evidence proves otherwise.

## Risks
Stale inventory, unknown client/core semantics, counter reset and drift can invalidate assumptions.

## Compatibility
Ordinary nodes stay unchanged; CDN nodes are additive only for ACTIVE entitlement and explicit preset.

## Testing
Require isolated release, source-linked fixtures and relevant transport/subscription/metering/canary evidence.

## Rollback
Keep prior immutable release and disable only affected entitlement/edge; preserve usage, ledger and ordinary nodes.

## Decision
Propose isolated, evidence-gated billing suspension with explicit owner stop gates.

## Evidence
MASTER requirements, CONTEXT language and ADR_MAP routing apply; live facts remain UNVERIFIED until recorded.
