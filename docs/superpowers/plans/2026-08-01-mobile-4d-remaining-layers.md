# План для Codex: довести сцену Home до эталона владельца

**Ветка:** `codex/mobile-4d-deck` · **База:** `c2a6980` · **Область:** только PNG в
`design/mobile-asset-redraw/`. Android-код, атлас, генератор и ТВ — не трогать, импорт делает Claude.

## 1. Почему экран не похож

Замерено 01.08.2026 сравнением чистого арта атласа с эталоном
`design/mobile-4d-references/04-owner-selected-home-2026-07-31.jpg` — без единого элемента,
нарисованного кодом.

**Из семи слоёв сцены по эталону сделан ровно один — резной веер протоколов.** Остальные пять
(`wood`, `frame`, `cartouche`, `vines`, `ring`) — из более ранней генерации, это другой рисунок.
Консоли в атласе нет вовсе.

| Слой | Эталон | Атлас приложения |
|---|---|---|
| `frame` | плотная резьба, завитки по углам, лоза вплетена в рейки, самоцветы на рамках; резьба начинается в 8.6 dp от края | тонкая двойная золотая линия без орнамента |
| `cartouche` | небольшая табличка впритык к надписи, навершие с камнем | пустая плита почти во всю ширину, титул в ней теряется |
| `ring` | внешний Ø **333.9 dp**, толстое кольцо, внутренний пояс зелёной мозаики, четыре самоцвета по сторонам света; глаз заполняет диск до бронзы | внешний **365×304 dp**, тонкий голый овал, внутренний проём **229.1×205.7 dp** |
| `wood` | тёмное, мелкое волокно | светлее, доски шире и контрастнее |
| `vines` | вплетена в раму по периметру | редкие листья на досках |

⛔ **Главный видимый дефект — глаз висит в пустом кольце.** Ассет глаза 890×635 (пропорция 1.40)
стоит в почти круглом проёме 229.1×205.7 (пропорция 1.11): по бокам зазор 7 dp, **сверху и снизу
по 26 dp голой доски**. На эталоне мозаика идёт от век наружу и заполняет весь диск. Кодом это не
чинится — нужен слой, у которого мозаика доходит до бронзы.

## 3. Контракт файла — одинаков для всех

- PNG, RGBA, 8 бит на канал, **2160×4670**, sRGB **без ICC**, статический (не APNG).
- `_l` / `_c` / `_r` — **не части элемента, а весь элемент при свете слева, по центру и справа.**
  Альфа между тремя вариантами совпадает **пиксель-в-пиксель** (проверяется SHA-256), различается
  только RGB.
- Без текста, подписей, иконок, индикаторов выбора и центрального самоцвета — их рисует код.
- Без теней от соседних слоёв: межслойную тень рисует рантайм.
- Без остатков chroma-key: пикселей с `alpha > 0` и одновременно `R−G > 25` и `B−G > 25` быть не
  должно. ⛔ В прошлой поставке дуги их было 8711, все по кромке альфы.
- Материал: тёплая старая бронза. Целевой баланс на маске бронзы **R−G = +8…+12**, широкого
  тёплого рельефа **4–6 %** площади. ⛔ Не «редкие почти белые блики»: в прошлой дуге рельефа было
  0.6 % со средним (233,221,185), и это читалось как холодная зелень.

## 4. Числа по слоям

Всё в мастер-координатах 2160×4670; в скобках — тот же размер в dp при viewport 390×844
(коэффициент 5.538 по горизонтали, 5.533 по вертикали).

**`ring`** — внешний Ø **1849 px (333.9 dp)**, центр по оси `x=1080`. Внутренний проём должен быть
**заполнен мозаикой до бронзы**: между веками и кольцом голого дерева быть не должно. Четыре
самоцвета по сторонам света. Существующие `mobile_eye_*` не заменяются — мозаика их обрамляет.

**`frame`** — резьба начинается в **48 px (8.6 dp)** от края холста, идёт по всему периметру,
завитки по углам, самоцветы на рейках.

**`cartouche`** — табличка по надписи, не во всю ширину. Титул рисуется кодом Playfair 46 sp и
занимает **254 dp** по горизонтали в зоне `(69,54)–(323,88)` dp; табличка должна обрамлять именно
её, с запасом, а не растягиваться на 360 dp.

**`arc`** — по отдельной спеке: bbox `(0,3150)–(2160,3905)`, семь ячеек, центры
`216, 504, 792, 1080, 1368, 1656, 1944 px`, ячейка не меньше `244×255 px`, разделителя на оси
`x=1080` нет.

**`console`** — по отдельной спеке: bbox `(44,4071)–(2116,4647)`, три пустые зоны действий.

## 5. Приёмка

Автоматически, до передачи:

1. размер, RGBA8, отсутствие ICC и APNG;
2. alpha bbox каждой группы попадает в заявленную зону;
3. SHA-256 альфы совпадает внутри `_l/_c/_r`;
4. RGB между соседними вариантами света различается (копия файла запрещена);
5. остатка magenta нет по критерию из §3;
6. остальные файлы комплекта не изменены (SHA-256).

Глазами: доска сравнения 390×844 рядом с эталоном; `_l/_c/_r` читаются как один предмет под разным
светом, а не как три рисунка; на прозрачных краях нет белой, чёрной или пурпурной каймы.
