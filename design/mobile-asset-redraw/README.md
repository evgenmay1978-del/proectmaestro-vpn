# MaestroVPN mobile asset redraw

Здесь находится готовый исходный комплект для чистой пересборки мобильного
главного экрана. Полные требования и критерии приёмки описаны в
[`SPEC.md`](SPEC.md).

## Содержимое

- [`source/`](source/) — 15 PNG: пять слоёв × свет слева, по центру и справа;
- [`PREVIEW_c.png`](PREVIEW_c.png) — контрольная сборка центрального света без
  текста и глаза.

Каждый файл в `source/` имеет холст 2160×4670, 8 бит на канал и sRGB без
ICC-профиля. `home_wood_*` — RGB; остальные слои — RGBA.

## Порядок сборки

```text
home_wood
home_frame
home_cartouche
home_vines
home_ring
existing mobile_eye_* layers
Playfair title and interactive UI
```

Все слои накладываются в координатах полного холста без ручной подгонки. Варианты
`_l`, `_c`, `_r` внутри каждого слоя имеют одну и ту же альфа-геометрию.

## Жёсткая граница внедрения

- не класть новый комплект поверх `mobile_home_scene.webp`;
- не запекать в арт текст, глаз или тени между слоями;
- после миграции и проверки ссылок удалить заменённый mobile-only плоский
  композит и мёртвые мобильные слои;
- не менять `tvm_*`, TV-компоненты, D-pad/focus/Back и ветки `isTv`;
- не перегенерировать исходники без отдельного решения владельца.

## Детерминированные runtime-атласы

Скрипт [`../../ops/mobile-4d-assets.py`](../../ops/mobile-4d-assets.py) проверяет
точный набор исходников, режимы и общую альфа-геометрию, затем собирает
lossless WebP-атласы с одинаковой раскладкой для света слева, по центру и
справа. Каждый фрагмент хранится с двухпиксельным edge-extruded gutter, а
размер страницы не превышает 2048×2048.

```powershell
python ops/mobile-4d-assets.py
python ops/mobile-4d-assets.py --check
```

Для байтово-детерминированного результата требуется зафиксированный toolchain:
Pillow 11.3.0 с libwebp 1.5.0. Скрипт проверяет обе версии до генерации.

Обычный запуск выполняет полную попиксельную реконструкцию 15 мастер-слоёв и
обновляет `app/src/main/assets/mobile_4d/` вместе с Kotlin-манифестом. Режим
`--check` строит те же файлы во временном каталоге, повторяет реконструкцию и
проверяет отсутствие дрейфа, не изменяя tracked output.

Манифест фиксирует runtime-политику декодирования: ширина viewport округляется
до шага 64 px и ограничивается 1620 px; бюджет декодированного арта — не более
40% `ActivityManager.memoryClass`. На low-RAM устройствах используется только
центральный свет, ширина ограничивается 1080 px, а tilt relighting отключается.
