# MaestroVPN — точка входа для Codex, Claude и других агентов

Перед любой работой в этом репозитории:

1. Полностью прочитать [`CONTEXT_HANDOFF.md`](CONTEXT_HANDOFF.md).
2. Прочитать переносимый навык
   [`.agents/skills/project-master/SKILL.md`](.agents/skills/project-master/SKILL.md)
   и следовать ему. Для серверной работы до первой команды полностью прочитать
   [`SERVER_RUNBOOK.md`](SERVER_RUNBOOK.md).
3. Проверить текущие ветку, HEAD, remotes и `git status`; volatile-факты из
   handoff и runbook перепроверять, а не принимать навсегда.
4. Для новой/незавершённой работы сверить [`BACKLOG.md`](BACKLOG.md) и читать
   только относящиеся к задаче спецификации/планы.
5. Сохранять чужие tracked/untracked изменения. Не выполнять очистку, reset,
   merge, release, OTA, production deploy или data mutation без прямого
   разрешения владельца.

Перед любой server/network/production mutation и перед повтором неудачной
операции использовать `python ops/maestro-repetition-guard.py ...`. В журнал
передавать только смысловые идентификаторы без команд, URL, логинов и секретов.
После ошибки обязательно записать `fail`, установить причину, записать
`correct` с другим семейством действий и только затем повторять. Успешный
результат завершать `success` с безопасным evidence-code.

Ничего не угадывать по старой памяти: unit, `ExecStart`, `WorkingDirectory`,
env-файл, state path/format, nginx-конфиг, порт и live commit сначала
обнаруживаются read-only командами. Пароли, токены, ключи, `.env`, приватные
пути панелей, полные subscription URL и данные клиентов не выводить и не
коммитить.

Компьютер владельца слабый: тяжёлые Gradle/APK/atlas/simulator задачи выполнять
на GitHub Actions. Локально допустимы Git, документация и лёгкие проверки.
Работать GitHub-first: материальный checkpoint не считается переданным, пока
ветка не запушена и remote SHA не проверен.

Отвечать владельцу по-русски. TV-интерфейс и TV-ассеты не менять без отдельного
прямого запроса; mobile-задача не разрешает правки `tvm_*`, TV-компонентов,
D-pad/focus/Back, TV-геометрии и веток `isTv`.

Если live-состояние, ветка, коммит, PR, выполненные проверки, риск или следующий
шаг материально изменились, перед завершением обновить `CONTEXT_HANDOFF.md`, а
операционную процедуру — `SERVER_RUNBOOK.md`.
