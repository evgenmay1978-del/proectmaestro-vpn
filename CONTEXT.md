# Canonical domain language

Customer; Device; VPN Account; Xray User; White-List Entitlement; Transport Profile; Compatibility Preset; Origin Route; Edge Candidate; Approved Edge; Transport Release; Meter Epoch; Usage Sample; Usage Interval; Billing Period; Tariff Snapshot; Ledger Entry; Suspension; Grace; Canary; Rollback Point.

Never call all of these “client”. A multi-node data plane means independently reconciled sidecars on S1/S2/S3/S4, not one shared production process.
