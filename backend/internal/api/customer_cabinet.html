Когда нужен CDN

Обычная подписка — VPN на каждый день. CDN — отдельный пакет ГБ для мобильного интернета с белыми списками, когда обычный VPN не работает.

Дома и по Wi-Fi выбирайте обычный VLESS или Hy2 и выключайте CDN, чтобы не тратить ГБ. Выключайте CDN вручную при переходе на Wi-Fi.

Сохраните адрес этого кабинета заранее. Для покупки здесь Telegram не нужен.

Обычная подписка

Пакет CDN не продлевает обычную подписку. Продление обычного VPN — через привычное меню покупки.

Вставьте ссылку в поле «URL подписки» клиента. После начисления ГБ обновите подписку в клиенте. В MaestroVPN используйте свой логин.
