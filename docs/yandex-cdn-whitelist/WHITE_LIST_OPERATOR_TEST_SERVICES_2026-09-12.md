# Сервисы проверки белых списков по операторам — 12.09.2026

## Основной результат

Найден BSCHEKER: https://t.me/bschekbot

Публичная карточка Telegram называет его сервисом проверки доступа к переданному IP. Публичный проект ru-cidr указывает поддержку МТС, T2, МегаФона, Билайна и Т-Мобайла. Отдельное публичное обсуждение вопроса «как проверить VPN/IP через белые списки» также рекомендует @bschekbot.

Без запуска диалога с ботом публично не подтверждены цена, лимиты, регионы, точная тестовая методика, проверяемые порты и формат результата. Боту пока не отправлялись IP или другие данные MaestroVPN.

## Что такой тест подтверждает

Если BSCHEKER действительно соединяется с указанным IP через SIM каждого оператора, результат полезен для проверки L3-доступности и, в зависимости от выбранного режима, TCP-порта. Это подходит для первичного отбора IP/подсетей под прямой relay или Reality.

Положительный результат не доказывает:

- прохождение нужного TLS SNI и HTTP Host;
- работу конкретного XHTTP path;
- совместимость client/server Xray;
- передачу полезной нагрузки после подключения;
- длительный открытый поток и idle resume;
- работу конкретной подписки HAPP/INCY/Karing;
- одинаковое поведение во всех регионах России.

Для CDN shared edge проверка одного IP особенно ограничена: разрешённый edge IP ещё не подтверждает маршрутизацию нашего hostname к origin. Поэтому после BSCHEKER нужен отдельный end-to-end запрос через точную клиентскую конфигурацию.

## Альтернативы

### Freedom Checker

https://freedomchecker.ateo.digital/

Сервис использует физические узлы, модемы и отдельные eSIM российских операторов в Европейской части, Сибири и на Дальнем Востоке. Он поднимает VPN и проверяет открытие реального контента. Цикл повторяется каждые 4–6 часов, публикуются JSON snapshots. Это более сильная end-to-end проверка, но нельзя мгновенно передать произвольный IP: сервисы добавляются в мониторинг отдельно. Методика прямо предупреждает, что доступные операторы и три макрорегиона не покрывают всю Россию.

### Роспингнадзор

https://t.me/rospingnadzorbot

Публичная карточка: «[скоро]», проверка IP на белосписочность, МегаФон, регион 61. Для проверки по всем операторам не подходит.

### WhiteListCheck

https://github.com/dmitrystarosta/WhiteListCheck

Открытое Android-приложение определяет режим белого списка непосредственно на текущем телефоне. Оно полезно владельцу конкретной SIM, но не заменяет удалённую матрицу операторов.

## Применение к MaestroVPN

1. Передавать BSCHEKER только конкретный публичный IP, который разрешил проверить владелец.
2. Не передавать subscription URL, UUID, XHTTP secret path, Reality keys, токены, конфиги и данные клиентов.
3. Зафиксировать оператор, регион/узел, порт, время и результат.
4. После положительного IP-чека провести один реальный HTTPS-запрос через точную MaestroVPN-конфигурацию.
5. Для CDN отдельно проверить TLS hostname, Host, XHTTP path, начальный запрос, передачу данных и повтор после idle.
