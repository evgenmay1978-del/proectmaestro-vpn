# MaestroVPN Telegram Growth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Запустить оформленный и наполненный Telegram-канал MaestroVPN без YouTube и без расходов на рекламу.

**Architecture:** Канал служит публичной витриной доверия, существующий бот — точкой регистрации, пробного доступа и оплаты. На первом этапе меняются только название/описание/контент канала; серверы, VPN, CDN, платежи и приложение не затрагиваются.

**Tech Stack:** Telegram channel @maestrovpn, @MaestroSecureVPN_bot, существующая реферальная система.

## Global Constraints

- Не публиковать секреты, IP, UUID, подписки, paths, конфиги и данные клиентов.
- Не покупать рекламу и не принимать финансовые условия без отдельного бюджета владельца.
- Не обещать универсальную работу у всех операторов и регионов.
- Не создавать YouTube-канал.
- Не запускать сборки или тестовые кампании.
